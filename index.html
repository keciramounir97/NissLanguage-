Niss code

NissLanguage

Un code de filles : emojis, surnoms, chiffres maquillés. Sept humeurs, trois langues.

Comment lire

  1. Un mot est un jeton. Les jetons se séparent par des espaces.
  2. La plus longue suite connue gagne. 💯 👍 veut dire « ça va », pas « vraiment » puis « oui ».
  3. Des lettres collées épellent un mot. se lit « hi », donc salut.
  4. L'humeur ne change pas l'écriture. Elle change le sens. En registre contraire, la phrase veut dire l'inverse.
